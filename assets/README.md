# Assets

Branding and illustration files that ship with the app.

| Directory | Contents |
|---|---|
| `branding/` | The product mark and wordmark. Sosumi's own, not Apple's. |
| `icons/` | The application icon at the sizes each packaging format needs. |
| `illustrations/` | Empty-state and onboarding artwork. |

Two rules apply to everything here:

- **No Apple marks.** No Apple logo, Apple Music wordmark, or Apple trade dress.
  The app is not affiliated and must not look as though it is. See
  `docs/LEGAL-SCOPE.md`.
- **Every asset is our own work** or carries a licence compatible with MIT, and
  is credited in the README if it came from elsewhere.
